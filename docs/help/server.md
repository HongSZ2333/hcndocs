# 新手用户如何购买服务器后并链接使用教程
## 购买服务器
### 打开官网

首先打开官网链接 [idc.cjsyun.cn](idc.cjsyun.cn) 注册/登录
![](https://dl.img.timecdn.cn/2025/07/20/2025-07-20-13.50.40.png)


### 购买服务器

登录后在控制台页面找到 <mark>订购产品</mark> 点击进入，找到您所需的服务器购买
![](https://dl2.img.timecdn.cn/2025/07/20/PixPin_2025-07-20_14-43-35.png)
![](https://dl3.img.timecdn.cn/2025/07/20/PixPin_2025-07-20_14-45-58.png)

## 链接服务器

首先进入控制台，点击 <mark>游戏云VPS/云服务器/物理机</mark> 找到您刚刚购买的服务器，点击管理
![](https://dl.img.timecdn.cn/2025/07/20/PixPin_2025-07-20_14-48-36.png)

### Windows链接

首先在服务器控制台，将您服务器的 远程地址以及用户名密码复制下来（如下图）

然后在电脑中按 <mark>WIN键</mark>，输入 <mark>远程桌面连接</mark> 并回车

将IP输入其中（如下图）后点击 <mark>编辑->更多选项->使用其他账户</mark> 将复制的用户名密码填入（如下图）点击确定就链接成功了

![](https://dl3.img.timecdn.cn/2025/07/20/PixPin_2025-07-20_14-58-35.png)
![](https://dl2.img.timecdn.cn/2025/07/20/PixPin_2025-07-20_14-56-43.png)
![](https://dl3.img.timecdn.cn/2025/07/20/PixPin_2025-07-20_15-19-34.png)

### Linux链接
> [!warning] 注意：Linux服需要安装对应的ssh工具进行链接，这里以 Xshell 进行演示

首先在服务器控制台，将您服务器的 远程地址以及用户名密码复制下来（如下图）

其次打开 <mark>Xshell</mark> 工具 点击 <mark>新建</mark> 将复制的 <mark>远程地址</mark> 填入其中（如下图）

然后点击 <mark>用户身份验证</mark> 将 <mark>用户名密码</mark> 填入其中（如下图）并点击 <mark>确定</mark>

> [!warning] 注意：如果不让填写密码，下方的框中勾选 password 其余不要勾选

最后选中刚刚添加的服务器，点击 <mark>链接</mark> 即可
